01 FISHINGLOG / REST API
PERSONAL PROJECT · JAVA · SPRING BOOT · POSTGRESQL

A fishing log,
built to last.

FishingLog is a REST API for storing and exploring fish records, built with separate controller, service, and repository layers.

  • Create, read, update, and delete fish records.
  • Search by species and lake, count records, and retrieve the top-K fish by weight.
  • Persist records in PostgreSQL through Spring Data JPA, with database-generated IDs.

I tested endpoints in Postman and moved the database password out of the source code. Unit tests for updateFish() check that changed fields are saved, the updated fish is returned, and a missing ID produces an error. The current tests work, with more coverage still to be written.
